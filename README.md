# Кабинет сексолога

React-приложение для карты сексологического обследования (бланки мужского и женского пола, 21.10.2024).

Данные остаются **только в браузере** (`localStorage`). На GitHub ничего о пациенте не уходит.

## Как открыть локально

Нужен Node.js. Затем `Открыть кабинет.bat` или:

```bash
npm install
npm run dev
```

Адрес: [http://localhost:5173/questionare/](http://localhost:5173/questionare/)

## Рабочий процесс

**Карта обследования** — основной экран. При открытии показывается обзор с прогрессом по 10 секциям бланка:

1. Паспорт  
2. Жалобы  
3. Функция  
4. Анамнез  
5. Сома  
6. Пара  
7. ЭЗ  
8. Осмотр  
9. МКБ  
10. План  

Секции «первого визита» (жалобы, функция, сома, МКБ, план) подсвечены отдельно. Прогресс виден в шапке и на каждой секции.

**Быстрый приём** — экспресс-режим для первого визита (6 шагов). Заполняет те же поля карты; после — переход в нужные секции или протокол.

**Протокол** — текст для амбулаторной карты с индикатором заполнения секций.

Опросники (темперамент, OPD-3, коморбидность и др.) доступны из секций карты по показаниям.

## Темперамент

Полный бланк из папки «Опросы» (13 пунктов, м/ж). Интерпретация: база / драйв / торможение / абстиненция.

Рядом клинические оси **Dual Control** (Bancroft, Janssen): SES, SIS1, SIS2.
