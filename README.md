# Кабинет сексолога

Адаптивное структурированное интервью для сексолога-психотерапевта.

Данные остаются **только в браузере** (`localStorage`). На GitHub ничего о пациенте не уходит.

## Локально

```bash
npm install
npm run dev
```

Адрес: http://localhost:5173/questionare/

## Поток

1. **Выбор пола** — первый экран (разный визуальный язык для м/ж)
2. **Симптомы** — два уровня: домен → уточнение
3. **Интервью** — модули по симптомам
4. **Опросники** — IIEF-5, PEDT, FSFI-ключевые, ASEX, PHQ-2 с автоскором
5. **Структура** — оси нарушения + формулировка + план
6. **Протокол** — копирование и печать

Ведение случая: несколько визитов в одном случае (`+ Визит`).
