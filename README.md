# Кабинет сексолога

React-приложение для первого приёма и карты сексологического обследования (бланки мужского и женского пола, 21.10.2024).

Данные остаются **только в браузере** (`localStorage`). На GitHub ничего о пациенте не уходит.

## Как открыть локально

Нужен Node.js. Затем `Открыть кабинет.bat` или:

```bash
npm install
npm run dev
```

Адрес: [http://localhost:5173/questionare/](http://localhost:5173/questionare/)

## Сценарий приёма

Пациент приходит с сексологической проблемой. На старте — шесть шагов, каждый можно пропустить:

1. Кто пришёл  
2. Жалоба и фокус  
3. Функция (эрекция/эякуляция или любрикация/оргазм/пенетрация)  
4. Соматика, антидепрессанты, суицидальный риск  
5. Темперамент экспресс + Dual Control  
6. Снимок в протокол  

Пол переключается в шапке. Дальше — полная карта, интервью с «?», OPD-3, коморбидность, личность F60, раздатки.

## Темперамент

Полный бланк из папки «Опросы» (13 пунктов, м/ж). Интерпретация: база / драйв / торможение / абстиненция.

Рядом клинические оси **Dual Control** (Bancroft, Janssen): SES (возбуждение), SIS1 (торможение из‑за страха неудачи), SIS2 (торможение из‑за последствий). Пункты SIS/SES не копируются — только ваша оценка 1–4.
